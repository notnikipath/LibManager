# LibManager — design system

Based on UI/UX Pro Max (nextlevelbuilder/ui-ux-pro-max-skill).

Product match verified; adopted a restrained dashboard layout instead of decorative effects.

- Direction: Library workspace; flat surfaces, readable data and clear primary actions.
- Primary: #57534e; page: #f7f5f0; standard text: #172033.
- Typography: Segoe UI / system sans; tabular numbers for metrics; no remote font dependency for the core UI.
- Spacing: 4/8px scale, 16–24px panel padding, 12px radius.
- Keyboard: skip link, section anchors, visible 3px focus rings.
- Forms: visible labels, 44px fields and buttons, feedback for pending requests.
- Responsive: 375 / 768 / 1024 / 1440px; panels stack and controls wrap.
- Motion: short color feedback; all motion disabled under prefers-reduced-motion.
- Dark mode: explicit paired foreground/surface tokens.
- Preserve business logic and existing workflows.
